# Zen Find

Zen Browser 原生查找栏的 CSS 重设计 Mod。

本项目只重设计原生 `findbar` 的外观和布局；原有查找功能、键盘快捷键及无障碍行为由 Zen/Firefox 保持负责。

## 当前状态

项目已初始化，等待确认目标 Zen 版本和查找栏设计方向后实现样式。

## 本地安装

在 Zen 的 Mod 管理界面中选择从本地目录安装，并选择本项目目录。Zen 应读取 `theme.json`，再加载 `chrome.css`。

具体菜单名称可能随 Zen 版本变化；安装前请确认当前版本支持本地 Mod。

## 开发

1. 在 Zen 中启用本地 Mod。
2. 修改 `src/` 中相应样式。
3. 重新加载或重新启用 Mod。
4. 按 `AGENTS.md` 的验证场景检查原生查找栏。
